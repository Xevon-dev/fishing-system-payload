# FishTrack

FishTrack — сайт про риболовлю. Тексти та фото на сайті можна змінювати в адмінці Payload. Вміст зберігається в базі Neon.

## Що є в проєкті

- `frontend` — сайт, який бачать відвідувачі.
- `cms` — адмінка, де редагується сайт.
- `Neon` — база даних для збереження вмісту.

## Запуск на комп’ютері

Спочатку створи файл `cms/.env` зі змінними `DATABASE_URL` і `PAYLOAD_SECRET`. Не надсилай ці значення іншим і не додавай файл `.env` у Git.

У першому терміналі запусти адмінку:

```bash
cd cms
npm install
npm run dev
```

Адмінка: <http://localhost:3000/admin>

У другому терміналі запусти сайт:

```bash
cd frontend
npm install
npm run dev
```

Сайт: <http://localhost:5173>

## Як змінити сайт

1. Відкрий адмінку й увійди.
2. У **Pages** редагуй блоки головної сторінки.
3. У **Загальних налаштуваннях** редагуй назву, меню та футер.
4. Натисни **Save** й онови сайт.
